# 参考画9枚の対応表

承認済みのカラー参考画と原資料を照合した記録。[承認済みの生成画像9枚](../scenes/shinjuku/kabukicho/1976/references/README.md)を原寸PNGとして公開した。当時の実写原本は転載せず、[機械可読の索引](../scenes/shinjuku/kabukicho/1976/references/approved-colour-index.json)に各版のSHA-256を残した。カラー化された色や生成された細部は、史実の証拠には加算しない。

| ID | 原資料の年代と対象 | 今回の用途・制約 | 出典確認 |
| --- | --- | --- | --- |
| R01 | 1978 / 一番街入口・昼の臨場感 | 入口の構図・周辺外観。門の1976年時点の形状は未確定。 | 東洋経済の掲載写真で1978年・吉野純治撮影を確認 |
| R02 | 1975 / 劇場前広場・人のいる午後 | 広場・街路灯と旧コマ劇場の一部。正面全体の根拠には不足。 | 観光協会の1975年写真と博物館目録の対応 |
| R03 | 1972 / ミラノ座・カラー資料に基づく昼景 | ミラノ座の外観・素材。コマ劇場とは区別。 | 所有者の一次目録で1972年を確認 |
| R04 | 1977 / 歌舞伎町・ネオンが照らす夜 | 看板と夜の光。経路上の正確な位置は未同定。 | 原資料のラベルのみ・原典の書誌未回収 |
| R05 | Venue slide says 1976; capture year uncertain / ミラノ座入口・映画看板の実在感 | ミラノ座の部分的な入口と広告。撮影年は未確認。 | 会場スライドの1976年表記・撮影年未確認 |
| R06 | 1976 / Club USA・入口の光と質感 | 入口・階段・電球。住所と経路上の位置は未確認。 | 原資料のラベルのみ・原典の書誌未回収 |
| R07 | 1976 / ゴールデン街・昼の路地の空気 | ゴールデン街。今回の経路の建物・道幅には使わない。 | JPCA NEWS41 p5で1976年と中谷吉隆のクレジットを確認 |
| R08 | 1972 / 一番街の旧門・街頭の人波 | 直線状の旧門。1976年までの存続・背面・寸法は未確認。 | 1972年の原資料。博物館ID7378は原典照合を進める候補 |
| R09 | 1971 / ミラノ座正面・街を歩く視点 | ミラノ座の1971年の外観。当年の広告を1976年へ転用しない。 | 所有者の一次目録で1971年を確認 |

R01・R08の門の形状は異なる。[組合の2013年改修記録](https://kabukichojimukyoku.seesaa.net/article/2013-12-18.html)は1969年以来という説明と後年の改修寸法を記載するが、これだけで1976年の門を確定しない。

R03・R05・R09はミラノ座、R07は経路外のゴールデン街。旧コマ劇場の正面全体を裏付ける資料は引き続き補う。
