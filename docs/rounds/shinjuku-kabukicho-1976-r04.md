# ラウンド記録：shinjuku-kabukicho-1976 / r04

## 今回の修正と成果物

批評のたびに、指摘への修正を1回ずつ行った。ラウンドaは最初の描画、bは1回目の修正後、cは2回目の修正後。

| 問題ID | 場所 | 変更内容 | 結果 |
| --- | --- | --- | --- |
| r04-1 | 全地点の光 | AgXからPBR Neutralへ替えた。空の濁り・霧・空の照り返しを減らした（AgXでは採用した門の赤が鮭色になり、全体が白く霞んだ） | 光と色の採点は、ラウンドbで多くの地点が8に届いた |
| r04-2 | 門の画角 | 固定地点`entrance-approach`は門の約10.8m手前で水平を向き、`under-gate`は門の面の上に立って通りの奥を向く。どちらも門が画角に入らない。R01由来のカメラは変えず、門の正面と裏面を見る補助視点を加え、2地点の役割を制作計画に書き直した | 決定として記録（下記） |
| r04-3 | 看板の文字 | 全看板が1種類の現代ゴシック体だった。看板ごとに書体（ゴシック・明朝・丸ゴシック・シーダ）を選び、字ごとに位置と筆の太さを揺らした。採用版の固定文字は既定の書体のまま揺らさない | 書体の種類は増えた。当時の字形との一致は主張しない |
| r04-4 | 看板の中身 | 業種に合う添え書きにした。電話番号は印字しない（実在の番号と重なるおそれ）。同じ店の看板が隣り合わないようにした。医院・不動産などは架空の姓を使う。実在名と重なる疑いのある語（ポエム、パピヨン、カルメン、ボレロ、ジュン、花月）を除外し、コードでも使えないようにした | ラウンドbでも重複が残ったため、cでさらに厳しくした |
| r04-5 | 電柱広告 | 「内科・小児科」の文字が板からはみ出していた。さらに、後から描く歩行者信号やかごの面と素材の画像上で重なり、下半分が上書きされて壊れていた。空いている場所へ移し、文字を板に収めた | 解消 |
| r04-6 | 季節 | 半袖・アロハ・七夕風の吹き流しと、コート・冬服・春の造花が同じ場面に混在していた。10月上旬にそろえた。1972年写真に見える街路灯の吹き流しと造花は臨時の装飾として既定では外した（`?decor=1972`で表示できる） | 解消 |
| r04-7 | 東宝会館の紋章 | 採用値（3重の輪、中心5.8m、半径1.5m）がありながら描いていなかった。文字も記号もない平らな輪として描き、看板と窓はその位置を避けた | 解消。横位置0.78はr03のスクリプトの値で、判断ファイルには書かれていない（未解決に記録） |
| r04-8 | ミラノ座 | 採用版の上部の窓（2段×10）を、記録なしに大きな看板で覆っていた。窓を戻し、看板はその上へ移した。柱がポスターケースを貫通していたため、ケースを柱の前へ出した | 解消（ラウンドc） |
| r04-9 | 人物 | 日陰の人物が自分で光って見えた。空の照り返し・白い服・肌の明るさを下げた。接地の影は、透明度の画像が緑の成分0で描かれていたため最初から表示されていなかった。これを直した。手を手のひら・指・親指に分け、靴底を平らにした。顔の比率を人ごとに変えた。同じ組の人物が双子に見えないよう服を選び直す。固定カメラの3.5〜9.5m手前の人物は、取り除かずに背を向けさせた。幹線道路の車道には、横断歩道以外で人を置かない | 改善。顔・手・服の造形は依然として最大の弱点（下記） |
| r04-10 | 素材・小物 | 劇場の大壁面の汚れを強めた。噴水の水面と縁の模様を直した。店内の商品を、ラベルのある小箱の並びにした。架線に1画素の線を重ねた（細い管が点線のように途切れていた）。屋上看板の脚を屋根スラブに置き、斜めの縞の縁取りをやめた。電話ボックスをコマ劇場の扉の前から移した | 改善 |
| r04-11 | 記録 | 描画記録へ、生成物ごとの根拠の段階、架空の店名の一覧、環境（three.jsとChromiumの版、元コミット、作業ツリーの未コミット変更の有無）を記録し、同じ出力先への追記を合成するようにした。ラウンドaの描画は未コミットの変更を含んでいたため、b・cはコミット後のきれいな状態から描いた | 解消 |
