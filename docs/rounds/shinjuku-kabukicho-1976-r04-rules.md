# r04 ラウンド条件：採用版をコード生成で高精細化する（three.js）

このラウンドの制作担当・批評担当が共通で参照する条件。ラウンド番号は、PR #7の調査（r02）と採用版の完成（r03）の後に続くr04とする（当初「r02」として起票したものを改名した）。当初はこのラウンドに限った作業条件として記録した。2026-11-02のユーザー指示で、合格基準・禁止リスト・コード生成の原則・根拠の段階・地点ごとの参考画を計画書（`docs/PRODUCTION_PLAN.md`）本体へ反映した。両者が食い違う場合は計画書を優先する。

## 共通の世界：r03の採用版

形・位置・高さ・文字の基準は、[r03の採用版](../RECONSTRUCTION_ADOPTED_1976.md)である。r04は見た目の作り込みであり、採用判断を変えない。

- 建物の量感は `data/derived/kabukicho-period-features.json` の採用高さ（1階3.2m刻み、経路から38m以内は上限24m）を使う。敷地は現代の輪郭を足場にしたもの。
- 門・コマ劇場・東宝会館・ミラノ座・噴水・街路灯・入口の階段は、`data/decisions/` の採用値（寸法・色・位置）と採用版の部材（fixtures）に合わせる。
- 採用版の固定文字45件（`text_nodes`）は、同じ文字・位置・向きで必ず描く。看板を増やすことはできるが、採用文字を変えたり消したりしない。
- 長回しのカメラは `cameras/adopted-walk.json`、固定診断用の6地点はR01のカメラ。静止画は両方から描く。

## 制作手段（ユーザー承認済み：2026-11-02「1番」）

- 静止画・試写の正式な描画手段は **three.js 0.170.0 ＋ ヘッドレスChromium（SwiftShaderによるCPU WebGL2）**。`viewer/` と `scripts/render_stills.mjs` で再現する。
- Blenderは導入可能な選択肢として残すが、このラウンドでは使わない。前回記録のBlender読み込み確認は、この環境では再現できない。
- 画像ファイル・外部の3Dモデル・HDRは読み込まない。メッシュ・テクスチャ・シェーダーはすべてコードで生成する。
- 文字は端末に入れたフォントで描く。フォントファイルはリポジトリに入れず、配布もしない。
  - 当初はIPAゴシック／WenQuanYi Zen Heiだけだった。
  - 2026-11-03に、看板の書体の種類を増やすためIPA明朝（IPAフォントライセンスv1.0）、モトヤLマルベリ3等幅・モトヤLシーダ3等幅（Apache-2.0）を加えた。歴史・地理の批評で「約1,100枚の看板がすべて現代のデジタルゴシック体」と指摘されたためである。
  - 導入：`apt-get install fonts-ipafont-gothic fonts-ipafont-mincho fonts-motoya-l-maruberi fonts-motoya-l-cedar fonts-wqy-zenhei`
  - 書体は看板ごとに選び、字ごとに位置と筆の太さを少し揺らして手描きらしさを出す（`viewer/src/world/signage/typeset.js`）。採用版の固定文字は既定の書体のまま揺らさない。
  - 書体の細部は制作上の選択であり、当時の看板の字形と一致を確かめたものではない。
- 光の設定 `clear-afternoon`（晴れた午後）は、R01・R02・R08に合わせた**見た目の作業上の選択**。1976年当日の季節・時刻・天候を主張するものではない。`neon-night` はR04との比較用。
- 作業上の季節は「10月上旬の晴れた午後（14時ごろ）」（2026-11-03）。太陽の位置と衣替えの時期に合わせた見た目の選択で、史実の日付ではない。服装と街路の飾りをこれにそろえる。1972年写真に見える街路灯の吹き流し・造花は臨時の装飾として既定では外し、`?decor=1972`で比較用に出せる。
- 昼の光は r04 でトーンマップをKhronos PBR Neutralに替えた（AgXでは採用した門の赤が鮭色になった）。

## ユーザーの決定（2026-11-02）

- **門の形**：湾曲した門（R01の形。元写真は1978年）を制作上の形とする。r03の採用判断 `kabukicho-gate-1976`（曲線型・白熱電球）と同じ。1976年時点の形は推測のままとする。直線状の門（R08、1972年）は反証として記録に残すが、r04では作らない。
- **不明箇所の扱い**：資料で確定できない部分は、制作を止めずに推測で補う。推測した部分は `period-plausible-generic` か `placeholder` として記録し、確認済みとは書かない。新しい資料が見つかったら置き換える。この扱いにより、未確定の門や劇場正面を理由に段階3・4の作り込みを止めない。

## 根拠の段階（生成物ごとに `ctx.tag()` で記録）

| 段階 | 意味 | 例 |
| --- | --- | --- |
| `source-derived` | 出典のある形・位置・文字 | PLATEAUの敷地形状、地形、門の「歌舞伎町一番街」の文字（R01・R08の元写真に写っている） |
| `adopted-inferred` | r03で採用した推定値に従う形・寸法・色 | 門・劇場・噴水・街路灯の採用寸法と色 |
| `period-plausible-generic` | 資料で特定できない部分を、年代らしい一般的な形で補ったもの | 店構え・窓・看板の業種名・架空の店名・街灯・車・人物 |
| `placeholder` | 形状を検討するための仮の物 | 採用判断のない部分の仮の形 |

- 実在の店名・企業名・商標・ロゴ・映画の題名・俳優の顔は使わない。看板の文字は、一般的な業種名（喫茶・麻雀・中華料理・洋品など）と、架空であることを明記した店名に限る。上演・上映の演目は描かない。
- 例外は、採用版の固定文字（門の「歌舞伎町一番街」、「ミラノ座」「コマ劇場」「コマ東宝」「プラザ劇場」「クラブハイツ」「入口」など）。各採用判断の根拠と推定の範囲に従って描く。ミラノ座の「MILANO」の欧文（R03・R09、1971〜1972年）も使ってよいが、年代差を記録する。企業の紋章・ロゴは描かない。
- 建物の高さと敷地はPLATEAU 2025年版（現代）を下敷きにしている。1976年の階数・高さとしては確認していない。

## 見た目の採点（主観。史実の証拠にはしない）

批評担当は地点ごとに、次の6項目を10点満点で採点する。

1. 構図の自然さ（参考画がある地点はその構図と比べる）
2. 光と色（グレーに沈みすぎず、彩度過多でもない）
3. 素材の実在感（汚れ・雨だれ・錆・ムラ）
4. 近景・中景・遠景の密度
5. 看板の読みやすさと年代の合い方
6. スロップがないこと

最終目標は、全項目8点以上かつ重大な指摘なし。r04の目標は、6地点すべてで初回の採点と重大な指摘の一覧を得て、1回以上の修正で点数を上げること。点数は見た目の主観評価にとどめ、歴史考証の合格判定には使わない。

## 禁止するスロップ

- 発光・ブルーム・霞で形状不足を隠すこと。昼間に強く光るネオン。レンズフレア。
- 意味をなさない日本語、偽の漢字、中国語の簡体字、ラテン文字の埋め草。縦書きで長音記号「ー」を横向きのまま並べること。
- 同じ外観・看板・人物が隣り合って繰り返されること。継ぎ目が見える素材の繰り返し。
- 汚れのないCGらしい清潔さ（すべての面に汚れ・退色・雨だれが要る）。全体がグレーに沈むこと。全体の彩度過多。
- 浮いている物、接地の影がない物、建物を貫通する物。
- 年代に合わない物：LED、液晶画面、現代の車、コンビニの看板、現代の道路標示（両端の線がない横断歩道など）、現代の自販機の形、樹脂製の現代的な看板。
- 実在のブランド・ロゴ。画面上の説明文字（地点ラベルなど）。

## 描画時間の目安

- 1920×1080の静止画を1地点あたり120秒以内（SwiftShader、4CPU）。作業中の確認は960×540でよい。
- 近景（経路から約40m以内）を最も細かく作り、遠景は簡略化する。
