## 参考にする方法

Cook Loop（`https://github.com/Leonxlnx/cook`）の作者の作品を参考にする。

- **ギリシャの世界（athenaion）**
  - 外部素材ゼロのthree.js、約4.5万行。
  - 描画は「ずらし描きの重ね合わせ」：4K静止画は16回、動画は8回の重ね描き。
  - 局所トーンマップ、ボリュームの雲、大気のかすみ。
  - 専門エージェント12体の並行作業で約45時間。
  - 人物は出てこない。
- **ピアニストの映像（afterglow）**
  - 人物の土台：MakeHumanの体を、BlenderのMPFBでスクリプトから自動生成。
  - 衣服と細部：衣服は布の物理計算で姿勢に合わせて着せる。髪・髭は手続き生成。手は高解像度の質感と産毛。
  - 骨格と動き：163関節の骨格。指の動きは逆運動学で計算。
  - 描画：1コマ16〜128回の重ね描き（ずらし・動きのぶれ・被写界深度）、PBR Neutralのトーンマップと色の補正。

本プロジェクトのビューアも、three.jsとヘッドレスChromeという同じ系統である。重ね描きと人物の作り直しを、同じ考え方で入れる。

## 作業の順番

### 0. PCの準備と測定（最初に必ず）

- `docs/SETUP_GPU_PC.md`の手順で準備し、GPUで描けることを確かめる（`--gpu`）。
- 固定6地点を1920×1080で描き、1地点あたりの時間を記録する。
- CPU描画（r04の公開画像）と並べ、差を確認する。
- 対話の確認画面（`npm run serve`）が、なめらかに動くことを確認する。

### 1. 重ね描きの描画（段階a。ユーザーの承認は不要）

1コマを、少しずつ条件を変えてN回描いて平均する。

- **ぎざぎざの除去**：画素以下のカメラのずらし。
- **柔らかい影**：太陽の方向を太陽の円盤の大きさの範囲でずらす。
- **被写界深度**：任意。
- **動きのぶれ**：動画用。歩行の時刻を、シャッターが開いている間で分ける。

加えて、次を入れる。

- 局所トーンマップ
- 色の補正（3D LUT）
- 大気のかすみ（距離による）
- 空の微妙な濃淡（形を隠す霞にしない）

既存の`main.js`の描画を拡張し、URLの引数（例：`spp=32`）で回数を指定できるようにする。世界は1回だけ作り、描画だけを繰り返す。

測定すること：1地点あたりの時間と、回数ごとの見た目の差（8・16・32・64回）。

### 2. 人物の作り直し（段階b。ユーザーの承認が必要）

- MakeHuman（CC0）の体を、BlenderのMPFBでスクリプトから20〜30種類作る（年齢・性別・体格を変える）。
- 1970年代の服（背広、ワイシャツ、ブラウス、スカート、学生服など）を、布の計算で着せる。髪を付ける。
- 骨格つきのglTFとして書き出す。同じ人物を詳細度違いで複数用意する。
- カメラの近く（約8m以内）だけ高精細にし、遠くは今の手続き生成の人物のままにする。
- 配置は`viewer/src/world/people/placement.js`の規則をそのまま使う。安定したID、服装の型、作業上の季節（10月上旬）も引き継ぐ。
- 動画に向けて、歩行の動き（足の運びと腕の振り）を付ける。今の人物は静止している。歩行の手がかりになるID・歩幅・位相は、`group.userData.people`にある。
- 外部素材ゼロの規則の例外になる。使う前に`docs/rounds/`のラウンド条件と`docs/ASSET_POLICY.md`へ例外を書き、生成した人物の出典記録（MakeHuman/MPFBの版、利用条件、生成スクリプト）を付ける。

### 3. 並行作業（段階c。ユーザーの承認が必要）

- 人物、建物の素材、看板、地面、大気と光、小物の担当を並行で動かす。各担当は、地点ごとの参考画と比べて直す。
- 毎回の独立批評（映像2人・歴史地理1人）は、r04と同じ`docs/templates/CRITIC_BRIEF.md`の形式で行う。依頼書の例は、r04で使った条件（地点ごとの参考画、採点6項目、スロップ8項目）を写す。
- 規模の目安：参考にした作品は約45時間、出力約1,100万トークン、API換算で約1.8〜2.3千ドルだった。着手前に、ユーザーへ規模と停止条件を示して承認を得る。

### 4. 静止画のユーザー承認と動画

- 固定6地点と補助視点を、新しい描画で出し直す。独立批評で合格に近づいたら、ユーザーに静止画を見せて承認を得る。
- 承認後に、入口15秒の試写（1920×1080・30fps、450コマ）を描く。歩行・人物の動き・文字の安定・露出を確認する。
- 動画は、世界を1回だけ作り、コマを連続して描く方式にする。1コマあたりの時間を測ってから、全経路（約4分18秒）の所要を見積もる。

## 変えないこと

- 共通の世界（採用版の形・位置・高さ・固定文字45件）、歩行軌道、固定6地点のカメラ。
- 根拠の段階の記録。推定を確認済みに格上げしない。
- 実在の店名・企業名・商標・ロゴ・演目を描かない。架空名の禁止語は`viewer/src/world/signage/vocab.js`の`BLOCKLIST`で、テストが検査する。
- 公開する画像とデータには出典記録を付ける（テストが検査する）。
