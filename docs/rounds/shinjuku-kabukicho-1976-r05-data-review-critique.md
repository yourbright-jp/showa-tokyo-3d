## 2. 致命的・重大な問題（優先順）

致命的（経路・建物の取り違え、劇場の向きの誤り）は見つからなかった。コマ劇場（南）、東宝会館（北）、ミラノ座（北西）の同定と、広場に向く面の向きは、1975年・1979年写真と航空写真の配置に矛盾しない。

### 重大1：コマ北端の採用外観が、1976年を挟む1975年・1979年写真と食い違う。r05ではむしろ1957年の様式を強めた（項目1）

- **画像領域**
  - `renders/r05-data-after/plaza-reveal.png`：コマ北端 x≈620–800, y≈580–740（窓2列、庇、入口のベイ、庇の上の「コマ東宝」x≈670–740, y≈672–698）
  - `renders/r05-data-after/koma-front.png`：コマ低層前面の北半分 x≈505–1000, y≈480–720（「コマ東宝」x≈620–730, y≈598–626）
  - `docs/previews/r05-data-review/plaza-reveal-toho-before-after.jpg` 下段：「コマ東宝」x≈1125–1245, y≈635–675
- **観察した事実**（公開ページを自分で閲覧。画面上で拡大しただけで、保存・転載はしていない）
  - 1979年（`photo_sthb1.jpg`、1320×1000）：東宝会館の階段の右に、窓のない白い壁がある（x≈700–1150, y≈250–600）。そこに二重の輪の紋章があり、中に欧文の「KOMA」と読める（x≈817–900, y≈338–437）。紋章の下に映画ポスターの掲示ケースがあり、上の帯は「コマ東宝劇場」と読める（x≈710–825, y≈495–512。解像度の制約あり）。その右に縦の垂れ幕がある（x≈990–1031, y≈248–520）。白い壁の先には、奥まった灰色の壁と、枠の上に立つ大きな欧文の箱文字「K」がある（x≈1122–1221, y≈462–553）。
  - 1975年（`history_shinjuku_1975.jpg`、660×400）：同じ白い壁に同じ形の同心円の紋章（x≈515–570, y≈90–145）、縦の垂れ幕（x≈593–618, y≈60–213）、下にポスターの掲示ケースがある。垂れ幕の文字はこの解像度では読めない。
  - 1975年と1979年の両方で、この白い壁に窓の列は見えない。庇の上に「コマ東宝」の箱文字が立つ形も見えない。
  - 採用モデルの同じ位置（フロンテージの比率0.81付近。東宝会館の階段の南隣）には、1957年の様式による窓2列、庇、入口、庇の上の「コマ東宝」がある。
- **参照資料**：shinjuku-plaza-1975、shinjuku-plaza-1979、shinjuku-koma-1957。判断ファイルの `contradictions`（Ring emblem…）、`r05-koma-name-canopy.counter_evidence` の3番目、`alternatives` の採用理由（"Matches the mounting seen in the only inspected Koma front photograph"）。
- **問題点**
  1. 「only inspected Koma front photograph」は、同じファイルの記録と矛盾する。1975年・1979年写真は、コマの広場側を一部写した実見済みの資料で、しかも1976年を前後から挟んでいる。19年前の1957年の様式を優先する理由が書かれていない。
  2. 資料で決まらない部分は推定してよいという指示はある。しかしこの北端については、近い年の資料で外観がある程度決まる。推定（1957年の様式の継続）が、近い年の証拠を上書きした形になっている。
  3. 退けた代案は4案（壁の文字を上げる／浅い庇／視点を変える／庇の上に立てる）で、近い年の資料にもとづく案が入っていない。
- **修正案**
  - 次の改訂で、コマの西面を「北の区間」と「南の区間」に分けて判断する。
    - 北の区間（東宝会館の階段に隣接する部分）：1975年・1979年に合わせ、窓のない淡い壁、ポスターの掲示ケースと上の帯、縦の垂れ幕の取り付け位置（演目は描かない）、低い庇の線にする。紋章は「実在のロゴ禁止」の規則に当たるため、輪の形を中立化するか例外として判断するかを明記する。「コマ東宝」は、この位置の映画館名として掲示ケースの帯などで扱う。
    - 南の区間：1957年の様式（庇の上の箱文字）を推定として残す。1979年の「K」も、枠の上に立つ独立した箱文字で、取り付け方はこの推定を支える。一方で欧文・大きな字という点では反証になる。両面を記録する。
  - `alternatives` に「1975/1979準拠の北の区間」を加え、採否と理由を書く。採らない場合も、1957年を優先する根拠を明記する。
  - 「only inspected Koma front photograph」を「入口を含む正面を写した唯一の実見写真（1957年）。1975・1979年は北端の広場側のみ」のように正確な言い方に直す。

### 重大2：東宝会館前面の縦の並びと紋章の帰属が、項目4の根拠と同じ写真に反したまま残る（r05で記録済み・未修正。項目4に関連）

- **問題点**：項目4の改訂は「下にガラス張りの階、その下にプラザ劇場」という観察を根拠にしている。それなのにモデルでは、その階に看板がある。「period-plausible-generic」は資料で特定できない部分に使う段階だが、ここは資料が並びを示している。前面9mのままでは写真の並びが収まらないこと（クラブハイツの帯が9mより高い可能性）は反証として記録されているが、解消されていない。
- **修正案**：重大1と同じ改訂で次を行う。
  1. 紋章を東宝会館の前面から外し、コマ北の区間へ移す（中立化した形で）。
  2. 看板をプラザ劇場の帯の下へ移す。プラザ劇場の帯とクラブハイツの帯の間はガラス張りの階にする。
  3. 1の結果に合わせて、庇・プラザ劇場の帯・前面の高さを再配分する（9mを維持するか、写真の並びに合わせて上げるかを代案として比べる）。
  4. sources.json と RECONSTRUCTION_ADOPTED の記述を直す。

### 重大3：1957年写真の根拠記述が原典と食い違ったまま残っている（項目1）

- **観察した事実**：1957年写真（675×480）の庇の上の箱文字は「コマ東宝」（x≈55–200, y≈125–190）と、もう一つの段の「コマシネマ」（x≈235–330, y≈180–240）と読める。庇の小さな名札も「コマ東宝」「コマシネマ」。r05の `contradictions` の再読み（コマ東宝／コマシネマ）は正しい。
- **問題点**：同じファイルの `evidence[shinjuku-koma-1957].what_supports` は「separate コマ劇場 / コマ東宝 lettering」のまま。`data/sources.json` の同じ資料の行も同文。作業ツリーの未コミット版 `docs/RECONSTRUCTION_ADOPTED_1976.md` の28行目も、「コマ劇場」「コマ東宝」の文字の根拠に1957年写真を挙げている。r05で見つかった読み違いが、根拠の欄に原典と食い違う確定的な記述として残っている。採用した「コマ劇場」という文字列が、写真に裏付けられているように見えてしまう。
- **修正案**：上記3か所を「コマ東宝／コマシネマ（1957年）。『コマ劇場』の文字列は写真で確認できず、施設名による制作上の選択」に直す。r02の調査記録は当時の記録として残し、訂正の注記だけを加える。

### 重大4：1979年の垂れ幕を誤読している（項目1）

- **観察した事実**：白い壁の縦の垂れ幕は、映画の題名と出演者名の下端に「上映中　コマ東宝」とある。コマの公演の垂れ幕ではなく、映画館コマ東宝の上映告知。下の掲示ケースの帯も「コマ東宝劇場」と読める（中程度の確度）。
- **問題点**：`contradictions` と `counter_evidence` は「a Koma production banner」と書いており、原典の読み違い。この資料は、1979年にコマ東宝の掲示がコマの広場側の北端にあったことを示す。つまり「コマ東宝」を比率0.81付近（北側）に置く採用を、位置について**支持する**証拠でもある（形は違う）。
- **修正案**：記述を直し、`r05-koma-name-canopy.evidence` に「位置を支持、形と取り付けは不一致」として加える。番組名は1976年へ持ち込まない（既存方針どおり）。

## 3. 軽微な残課題と、推定として残せる範囲

### 項目1（コマの名称）
- **1957年写真がどの面を写しているか、記録がない（資料不足）。** 写真は縁石のある車道沿いの長い壁面で、奥に舞台の塔（屋上の箱文字つき）がある。西の広場側か別の面かは、この1枚では決められない。判断ファイルは "plaza-facing western edge" に1957年の様式を当てているが、面の同定が推定であることを `inferred_elements` に明記すべき。
- 「No name is mounted flush on the wall below the canopy line」は言い過ぎ。庇の縁と掲示板の下に小さな名札（コマ東宝／コマシネマ）がある。大きな箱文字に限った記述に直す。
- 1957年写真では、歩行者と比べて庇がおおむね4m以上の高さに見える（遠近のある1枚からの印象で、測定ではない）。採用の庇下面3.1mは写真由来ではない推定値なので、「1957年の取り付け方に合わせた」という書き方が寸法まで写真由来だと誤解されないよう注記する。
- **推定として残せる範囲**：南の区間で、庇の上に独立した文字を立てる取り付け方（1957年の様式。1979年の「K」も取り付け方は同系統）。高さ0.15mの台座レール、0.25mの後退、文字中心3.895m。「コマ劇場」の文字列（写真での裏付けなしと明記したうえで）。

### 項目2（ミラノ座）
- 1971年の観察「北隣の建物が、アーチが起点まで下りる前に切っている」は、1971年の縮小画像では言い切れない（右端でもアーチはかなり下がっている）。1972年ではよりはっきりしている。1971年の記述を弱めるか、1972年を主な根拠にする。
- 航空写真で、ミラノの明るい屋根の東端と北隣の屋根の間の暗い帯は、私の読みでは約3〜4画素あった（判断ファイルは1.5〜2画素）。北隣屋根の南端を垂線でミラノの縁へ投影すると比率は約0.63〜0.66で、採用値0.66は許容範囲内。画素幅の記述は測り方を書くか、幅を持たせる。
- 補助視点 `r04-milano-front` は約6m南へ動いて正面幅の中央を向いた。このため、公開正面の北端と北隣の関係が画面右端（x≈1700–1920）にわずかしか映らない。両者の境界を斜めに見る診断視点が1つあるとよい。
- 1971年・1972年写真では、北隣は明るい色の高い建物で、横長の窓の帯が何層も重なっている。変更前の補助視点で見えた北隣の外観（`renders/r05-data-before/r04-milano-front.png` x≈1410–1920：古びた淡黄色の壁に縦看板）とは性格が違う。r05の範囲外だが、写真があるので次回、外観の推定根拠として記録するとよい。
- 1972年写真の左（南）にも高い建物があり、ミラノ正面の南端との関係は調べられていない（範囲外。資料不足）。
- `data/sources.json` の tokyu-milano-1971/1972 と gsi-gazo1 の行に、新しい判断（kabukicho-milano-1976、kabukicho-context-massing-1976）への `decision_records` がない（台帳の整合の問題）。
- **推定として残せる範囲**：公開正面の比率0.66、北隣は現代の外周と28mの上限、名称を公開正面の中央に置くこと。

### 項目3（背景建物の高さ・cef4146e）
- `bldg_cef4146e` の現代の外周（画素でおよそ x 219–223, y 213–219）は、現代の東宝ビル（`bldg_7506fc9f`）の外周と頂点を共有する（[222.4,215.3]、[222.8,213.8]）。現代の建物の付属物だという補強材料になるので、根拠に加えるとよい。
- 分類ファイルの reason は「the 1974-1978 aerial shows paved theatre forecourt and no separate roof here」と断定口調になっている。判断ファイルの「画像に写っていないことは、なかったことの証明ではない」という但し書きを入れる。航空写真上は東宝会館前の街路に見えるので、「forecourt」よりも「街路／前の空き地」のほうが正確。
- **推定として残せる範囲**：24件に現代の高さを残すこと（制作規則として）、`bldg_1ddffcee` の6.4m、cef4146e の省略。

### 項目4（クラブハイツ）
- 写真のクラブハイツは、暗い帯の上に立つ明るい色の箱文字。モデルはピンクの板に文字を載せている。色はカラー目標R02に由来する見た目の選択と思われ、史実の主張にしなければ推定として残せる。
- r02の調査記録の「左奥の高い棟にクラブハイツ」は、1979年写真では「前面の最上部の帯（その奥に高層棟）」と読むのが正しい。r05の読みに同意する。
- **推定として残せる範囲**：文字中心8.4m（9mの前面を維持する限りで）。帯の高さと文字の大きさは測定していないという記録も適切。

### 項目5（街路灯）
- 「2mの配置の不確かさの範囲内」というが、2m自体が仮定の値で、灯柱の位置を示す資料はない。正当化としては弱いが、構図上の選択と明記しているので許容する。
- 1975年・1979年写真では、複数球の街灯が東宝会館の前面と階段の前、コマの紋章の壁の前に立ち、文字や紋章に重なって見える。「劇場名への視線上に灯柱を置かない」という基準は構図のためのもので、写真の実際の状況とは逆向き。これを理由にした移動はこれ以上重ねない。北寄り（東宝会館前）にも灯柱があった可能性は、資料不足として記録しておくとよい。
- r03の記録には「配置の確度を上げるために、経路の都合で噴水を動かさない」という原則がある。r05の灯柱の移動（カメラの都合）との関係を、判断ファイルに一言書いておく。
- **推定として残せる範囲**：北 [192,246]、中 [197,261]。

### 範囲外で気づいた点（判定の対象外）
- 1957年写真の壁面には何段もの窓が上まで続いている。採用モデルの「8.5mの低層前面に小窓2列＋付柱のある無窓の20mの塊」とは形が違う（r03以来の推定）。
