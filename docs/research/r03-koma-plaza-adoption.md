# R03：旧コマ劇場・東宝会館・広場の採用決定

2026年11月2日。目標年代は1976年前後。ユーザーの「どうしてもわからなければ、お前が推測してよい」という指示に従い、制作を止めていた同定・外観・広場工作物を採用決定へ進めた。機械可読の施工値は[採用仕様](../../data/decisions/kabukicho-koma-plaza-1976.json)に記録した。採用案は完成しているが、史実の全項目を確認済みに変更したわけではない。

## 決めたこと

| 対象 | 採用案 | 根拠と推定の境界 |
| --- | --- | --- |
| 南側の屋根輪郭 | 新宿コマ劇場。広場に面する西側外壁を広場へ向く正面として使う | 東宝による施設史と航空写真の対応を採用。屋根から地上外周・入口軸を確定する図面は未確認 |
| 北隣の屋根輪郭 | 新宿東宝会館。低いプラザ劇場前面と、後退したクラブハイツ側の高層部を分ける | 東宝は1969年10月の会館完成を記録し、2011年の発表はコマ劇場との二つの跡地を区別。写真の低層壁・背後の高層棟を形態へ反映 |
| コマの外観 | 淡い鉱物質の外壁、壁面目地、小窓2列、庇と反復する入口。「コマ劇場」「コマ東宝」の文字 | 実見した1957年ごろの写真を形態資料にし、1976年への存続を推定。色・寸法・入口の正確な位置は造形上の採用値 |
| 東宝会館の外観 | 低層前面の円形意匠、庇、階段、後退した上層。文字は「プラザ劇場」「クラブハイツ」 | 1975年・1979年の実写を近接年資料として使う。1979年の映画広告は1976年へ持ち込まない |
| 噴水 | 航空写真の西側の楕円状地物を水盤と解釈し、中心 `[183,252]`、短半径4.8m・長半径8m、長軸は北から時計回り17°、縁高0.55mで採用 | 航空写真と後年の新宿区記録が噴水の存在を補強。楕円の同定、中心、半径、縁高、稼働状態は推定 |
| 広場の灯具 | 球形照明を複数付けた街路灯3基。高さ5m、7球、基礎半径0.30m | 1975年・1979年写真の様式を採用。正確な球数・基数・配置・寸法は推定の構成値 |
| 階段 | コマの入口前を総高0.30m・2段、東宝会館の入口を総高1.2m・6段として施工 | 写真の段差・階段を形態の根拠とする。正確な位置・高さ・踏面寸法は推定 |

従来の20m・28mという屋根高さは、形状検討の仮定を引き継ぐ。写真の遠近だけから測定高へ変更しない。低層前面を8.5m・9mとし、後ろのホール・塔を区別することで、一個の箱から一歩進める。コマの西側辺の長さ約35.95m、東宝会館の西側辺の長さ約32.42mは、採用した航空写真上の線分を座標変換した値であり、現地測量の精度を示さない。

## 確認した資料

- [東宝の施設史](https://www.toho.co.jp/real-estate/kabukicho/)はコマ劇場が1956年12月に完成し、2008年に閉館した流れを記録する。施設の存在と同定を支えるが、1976年の全外壁の色を証明する資料ではない。
- [東宝の沿革](https://www.toho.co.jp/company/history/)は新宿東宝会館の完成を1969年10月と記載する。この年はページ公開年ではなく、記録された出来事の年である。
- [TOHOシネマズの2011年7月発表](https://www.tohocinemas.co.jp/news/pdf/2011/110712a.pdf)は新宿コマ劇場・新宿東宝会館の二つの跡地を再開発対象として挙げる。
- [新宿観光振興協会「新宿区70年の歩み」](https://www.kanko-shinjuku.jp/special/-/article_1768.html)にある1957年ごろのコマ劇場写真と1975年の広場写真を、手元の原画素で実見した。1975年写真からは開放空間、段差、球形の街路灯、クラブハイツの文字を読める。噴水の中心座標や輪郭はこの写真から測っていない。
- [同協会「新宿区の変遷」](https://www.kanko-shinjuku.jp/special/-/article_1767.html)の1979年写真を実見した。低層のプラザ劇場側、円形意匠、階段と背後の高層部分を区別する形態資料として用いる。
- [国土地理院gazo1](https://maps.gsi.go.jp/development/ichiran.html)の既存4タイルを実見した。採用仕様の画素はズーム17、左上タイル`116399/51606`の512×512合成画像の原寸座標。拡大画像を見ても元の情報量が増えるわけではない。
- [新宿区の2012年度会議記録](https://www.city.shinjuku.lg.jp/content/000121601.pdf)はコマ劇場前の広場にかつて噴水があったことを説明する。これは存在の補強資料であり、1976年の水盤寸法の証拠ではない。

## 不一致をどう処理したか

未年代の東宝掲載写真に見える緑の壁と大きな欧文`Koma Stadium`は、1976年の外観と断定せず、今回の採用色・文字から外した。1957年写真にある「コマ東宝」は地下の映画館名として扱い、1969年完成の東宝会館と混同しない。北隣の階数を9階か12階かとする後年記述の差は、検証済みの階数に丸めず、今回の28mの仮定と後退した塔の形で扱う。

博物館写真9073の1977年3月という目録情報はあるが、詳細ページの取得は今回も502となり、原画素は見ていない。見ていない写真を確認済みの外観根拠へ追加せず、実見できた1957年・1975年・1979年の写真で採用案を構成した。資料へアクセスできないことを理由に制作を保留しないという判断であり、アクセス済みを装うものではない。

## 施工と検査への引き渡し

噴水は縁を含む楕円全体を通行不可の障害物にする。灯具は地面の基礎半径0.30mと支柱を障害物とし、高い球形照明の冠を地上通行幅に混同しない。階段は写真に見えることを理由に経路から無視せず、モデルが実際に出力する外形で通過検査する。配置の確度を上げるために経路へ都合よく噴水を動かすことはせず、必要なら歩く側の経路を迂回させる。

すべての部材は共通の地理原点と基準標高32mを使い、地形面へ接地する。写真のラスター、映画ポスター原画、生成参考画をテクスチャとして複製しない。引用した資料の権利が、この設定やコードのライセンスへ自動的に移るものでもない。今回は読める建物名を固定し、番組が特定されていない掲示面は独自の中立的な図形として扱う。


独立した形状検査を受け、東宝会館側は階段上昇1.2m＋扉高2.7mの上に0.25mを確保するよう、庇の下面を広場地面から4.15m、プラザ劇場の文字基準高を4.55mへ修正した。いずれも制作上の推定値であり、実測寸法ではない。


文字高の基準を可視字形の中心へ統一した後、庇上端との重なりを避けるため、コマ東宝の文字中心を地面から3.9m、プラザ劇場を4.95mに置いた。文字の実高さ0.85mを含めた配置上の推定値であり、上記の旧4.55mの案を置き換える。
