# R03：一番街入口の門を採用する

1976年の制作モデルには、**反り上がる赤い曲線型と白熱電球を採用する**。1978年と帰属された実写の外形を2年前へ遡って使う、明示的な推定である。2026年11月2日の「どうしてもわからなければ推測してよい」という指示に従い、R02で保留していた制作上の選択を完了した。1976年の形状が史料で証明されたという意味にはしない。

機械可読の採用値は[門の判断データ](../../data/decisions/kabukicho-gate-1976.json)に保存した。`decision_complete: true`、`historical_confidence: inferred`を併記し、採用判断と史実の確認度を分ける。

検索は1976年・昭和51年・一番街アーチを対象に追加したが、今回の取得資料内に1976年の門を直接確定できる写真は見つからなかった。写真原本は公開リポジトリへ転載していない。原画像の利用権は取得していない。

## 採用理由と退けた案

1978年の所蔵・掲載者による帰属は、対象年に最も近い外形資料である。組合の回顧とも一致する側を制作の既定値にし、直線型は別案として残す。1972〜1978年の具体的な掛け替え年は作らない。

| 案 | 判断 | 理由 |
| --- | --- | --- |
| 曲線型・白熱電球 | 採用 | 1978年実写を主に、1969年という回顧を補助に選ぶ。1976年への遡及は推定 |
| 1972年の直線型 | 別プリセットに保存 | 実写としての反証を保持する。対象年から4年前であり、今回の制作既定値にはしない |
| 門を置かない | 不採用 | ユーザーが求める入口をくぐる再構成に門が必要 |
| 直線型の表面と曲線型の裏面を合成 | 不採用 | 同じ門の表裏であるという証拠がなく、年代の矛盾を創作で隠すことになる |
| 2013年以後のLED・太陽電池付き | 不採用 | 対象年代より後の装備 |

「別入口だった」「祭りの仮設物だった」「1972年表記が誤りだった」といった説明は、あり得る仮説であって今回確認できた結論ではない。採用モデルはこの矛盾を解消したことにはしない。
