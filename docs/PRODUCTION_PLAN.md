# 制作計画

## 目標

1976年前後の新宿・歌舞伎町を、一番街入口から旧コマ劇場前へ歩いて撮影したような、連続した空間として再構成する。将来は昭和の東京の別地区・年代へ拡張する。

既存のカラー参考画は光・素材感の目標に使う。参考資料には1971〜1978年などの年代差があるため、目標年代の建物・門・広告に揃える考証を別途行う。

## 段階

1. **地理参照と史料整理**：対象範囲、道順、道幅、劇場の向き、資料の年代と利用条件を確認する。
2. **街区の骨格**：地面と建物を共通の縮尺で配置する。現代の建物を目標年代へ置き換える。
3. **歩行・カメラ確認**：同じ街区で一番街入口からコマ劇場前まで移動できる状態にする。
4. **6地点の基準静止画**：入口手前、門の直下、一番街中ほど、曲がり角、広場への出口、コマ劇場正面を確認する。
5. **入口15秒の試作**：歩行速度、見通し、看板文字、素材・肌・光の自然さを確認する。
6. **本編への拡張**：同じ空間と時間軸で30〜60秒、全経路へ拡張し、音響と最終レンダーを仕上げる。

## 初期カメラ案

- 高さ：約1.6m
- レンズ：35mm相当を起点に調整
- 速度：約1m/sを起点に、実測距離から尺を決める
- 試作：1080p以下で動線を確認
- 最終出力目標：3840×2160、30fps

これらは初期案であり、撮影結果や実測値ではない。季節・時刻・天候は基準静止画の確定時に一つの設定へ揃える。

## 合格条件

- 道順と縮尺が根拠資料と対応し、曲がる前後の建物配置が一致する。
- カメラに近い窓・庇・看板・店内に、移動しても保たれる奥行きがある。
- 読める看板の文字がフレーム間で別の文字に変わらない。
- 人物の接地、遮蔽前後の服装・位置、車と建物の関係に目立つ不連続がない。
- 光・露出・歩行速度が不自然に急変しない。
- 歴史・地理の確認と、映像・音の自然さをそれぞれ評価し、問題区間をタイムコードと修正対象で記録する。

作業時間、生成回数、費用は区間ごとに上限を設定し、各ラウンドの成果物と残る問題を記録する。
